## 🚀 Instrucciones de Despliegue

### GitHub Pages
```bash
git add .
git commit -m "Release v0.9: Production-ready build"
git push origin main
```
URL: https://username.github.io/slimefront/

### itch.io
1. Crear proyecto en itch.io
2. Subir archivos (excepto .git, node_modules)
3. Clasificar como "HTML"
4. Configurar como fullscreen

### Servidor Personal
1. Copiar archivos a servidor web
2. Asegurar HTTPS (audios requieren)
3. No necesita backend

## ⚠️ Limitaciones Conocidas

- Google Sounds pueden tener latencia en cargas lentas
- Algunos navegadores piden permiso antes de reproducir audio
- Canvas 2D tiene límite de tamaño (~16k px en algunos)
